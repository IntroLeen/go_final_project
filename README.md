# TODO List Server

## Описание проекта
Это простой веб-сервер для личного планировщика. Он умеет:
- раздавать фронтенд из папки `web`;
- хранить задачи в SQLite базе `scheduler.db`;
- через API добавлять, редактировать, удалять задачи;
- отмечать их выполненными и переносить по правилам повторений (`d N`, `y`).

Всё сделано по шагам из задания: от простого файлового сервера до полного CRUD для задач.

## Задания со звёздочкой
Не реализованы. Поддерживаются только базовые правила повторений (`d N`, `y`).

## Как запустить
1. Склонируйте проект и перейдите в корень.
2. Установите зависимости:
   ```bash
   go mod tidy
   ```
3. Запустите сервер:
   ```bash
   go run .
   ```
   По умолчанию сервер слушает `http://localhost:7540/`.

4. Параметры можно настраивать переменными окружения:
   - `TODO_PORT` — порт (по умолчанию 7540).
   - `TODO_DBFILE` — путь до файла базы данных (по умолчанию `scheduler.db` в корне проекта).

Откройте в браузере `http://localhost:7540/` и будет загружаться фронт.

## Как прогонять тесты
Тесты лежат в папке `tests`. Запускать их из корня проекта:

- Прогнать все тесты:
  ```bash
  go test ./tests
  ```
- Проверить только конкретный шаг, например список задач:
  ```bash
  go test -run ^TestTasks$ ./tests
  ```

### Настройки в `tests/settings.go`
- `Port` — должен совпадать с `TODO_PORT`, если вы меняли порт.
- `DBFile` — путь к базе для тестов. По умолчанию `../scheduler.db`.
- `FullNextDate` — ставьте `true`, если сделали поддержку всех правил повторений (в этом проекте оставляем `false`).
- `Search` — можно включить `true`, если хотите проверить поиск задач (для этого есть отдельный тест).
